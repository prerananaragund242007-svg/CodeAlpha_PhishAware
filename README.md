PhishAware – Interactive Phishing Awareness & Detection Platform

About the Project

PhishAware is an interactive cybersecurity awareness platform developed as part of the CodeAlpha Cyber Security Internship.

It helps users understand phishing attacks, recognise suspicious messages, identify fake websites and learn safe online practices through interactive activities.

Features

- Phishing Knowledge Hub: Learn about phishing, its types, warning signs and prevention.
- Email Risk Analyzer: Analyse sample messages for common phishing indicators using rule-based checks.
- Phishing Case Studies: Explore realistic online scam scenarios and safe responses.
- Phishing Detective: Identify warning signs in suspicious messages.
- Website Spotter: Practise recognising suspicious website addresses.
- Cyber Safety Challenge: Test cybersecurity knowledge through an interactive quiz.
- Learning Progress Dashboard: Track completed activities and quiz progress.
- Reporting Guide: Learn how to report cybercrime in India.

Technologies Used

- HTML5
- CSS3
- JavaScript

How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Explore the interactive learning activities.

You can also use the Live Server extension in Visual Studio Code.
